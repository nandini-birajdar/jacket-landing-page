Jacket Landing Page

A responsive jacket shopping landing page built using HTML and CSS.
The layout adapts well to both desktop and mobile screens.

Features:
- Responsive design for mobile and desktop
- Clean and modern UI
- Flexbox layout
- Hover effects

Technologies Used:
- HTML5
- CSS3

Project Structure:
- index.html
- style.css
- Images (PNG)

About:
This project was created for learning and practice purposes.
